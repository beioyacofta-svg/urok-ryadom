# Урок рядом

Семейная мобильная страница-помощник с уроками для Степана, Родиона, Алины и Полины.

## Публикация на GitHub Pages

Файлы размещаются в корне репозитория. В настройках GitHub нужно открыть `Settings → Pages`, выбрать `Deploy from a branch`, ветку `main` и папку `/ (root)`.

## Работа без интернета

Страница устанавливает service worker и после первого успешного открытия сохраняет интерфейс в кэше телефона. После этого её можно повторно открыть без сети, особенно если добавить страницу на главный экран.

Важно: офлайн открывается интерфейс. Ответы нейросети требуют подключения к интернету и работающего API на VPS.

## Текущий статус

Текстовый чат и распознавание фотографий подключены к OpenAI через защищённый API на VPS: секретный ключ не попадает в браузер или GitHub. Кнопка «+» открывает камеру или галерею, снимок уменьшается на устройстве и отправляется помощнику. Он учитывает выбранного ребёнка и класс, объясняет теорию сразу, а практические задания ведёт по шагам. Голосовые и сохранение реального прогресса — следующие этапы.
