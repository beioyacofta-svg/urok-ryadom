# Урок рядом

Семейная мобильная PWA, которая принимает текст или фотографию школьного задания, объясняет тему по возрасту ребёнка и ведёт к ответу через подсказки, а не выдаёт решение сразу.

## Публикация на GitHub Pages

Файлы размещаются в корне репозитория. В настройках GitHub нужно открыть `Settings → Pages`, выбрать `Deploy from a branch`, ветку `main` и папку `/ (root)`.

## Работа без интернета

Страница устанавливает service worker и после первого успешного открытия сохраняет интерфейс в кэше телефона. После этого её можно повторно открыть без сети, особенно если добавить страницу на главный экран.

Важно: офлайн открывается интерфейс. Ответы нейросети требуют подключения к интернету и работающего API на VPS.

## Текущий статус закрытого пилота

Текстовый чат и распознавание фотографий подключены к OpenAI через защищённый API на VPS: секретный ключ не попадает в браузер или GitHub. Кнопка «+» открывает камеру или галерею, снимок уменьшается на устройстве и отправляется помощнику. Помощник учитывает выбранный профиль, объясняет теорию сразу, а практические задания ведёт по шагам.

Версия подготовлена к закрытому пилоту с несколькими семьями:

- универсальный вход по логину и паролю вместо списка одной семьи;
- профили детей приходят из защищённой серверной конфигурации;
- локальные профили и переписки изолированы по `familyId`;
- родитель видит только профили своей семьи, ребёнок — только своё занятие;
- раздел «История» показывает реальные вопросы и ответы на устройстве вместо демонстрационных показателей;
- родитель может удалить все локальные данные семьи с устройства.

История хранится на устройстве до 30 дней, восстанавливается после перезагрузки страницы и передаётся помощнику как контекст следующего сообщения. Кнопка «Новый чат» очищает занятие только выбранного ребёнка.

## Что ещё не готово для открытой продажи

- самостоятельная регистрация и восстановление доступа;
- подтверждаемое согласие родителя и юридические документы;
- российское серверное хранение семейных данных и прогресса;
- оплата, подписка и ограничение по тарифу;
- настоящий педагогический отчёт и уведомления родителю;
- административная панель и поддержка пользователей.

Текущий формат — закрытый пилот с ручным созданием семейных аккаунтов. Подробности конфигурации находятся в `api/README.md`.

## Проверка

Автоматические проверки семейного доступа не требуют внешних пакетов:

```bash
node --test test/api-auth.test.mjs
```

Тесты проверяют родительский доступ, изоляцию детского профиля, отказ при неверном пароле и запрет отправки сообщения от чужого профиля.
