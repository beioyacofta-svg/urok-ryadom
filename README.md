# Урок рядом

Семейная мобильная страница-помощник с уроками для Степана, Родиона, Алины и Полины.

## Публикация на GitHub Pages

Файлы размещаются в корне репозитория. В настройках GitHub нужно открыть `Settings → Pages`, выбрать `Deploy from a branch`, ветку `main` и папку `/ (root)`.

## Работа без интернета

Страница устанавливает service worker и после первого успешного открытия сохраняет интерфейс в кэше телефона. После этого её можно повторно открыть без сети, особенно если добавить страницу на главный экран.

Важно: офлайн работает интерфейс и встроенная демонстрационная учебная логика. Настоящие ответы внешней нейросети без связи с сервером работать не смогут.

## Текущий статус

Это интерактивный семейный прототип. Он отвечает на несколько теоретических вопросов о дробях, ведёт по шагам через демонстрационный пример и принимает правильные ответы. Подключение полноценного ИИ и сохранение реального прогресса — следующий этап.
